# 05. Synergy-Driven Autopoiesis

## Mutual Repair Resource Scheduler

### Original vision

A biological network instantly reroutes instructions to reverse another organism’s decay.

### Evidence boundary

Resource sharing can support repair services; it is not instant biological rejuvenation or proof of shared metabolism.

### Buildable proposal

Schedule finite technician time, spare units, or laboratory capacity across requests, showing unmet need. The demonstration uses one interchangeable resource.

### Testable hypothesis

An explicit capacity-and-severity queue reduces hidden unmet demand compared with an unbounded task list.

### Baseline comparison

First-come-first-served scheduling using the same total resource budget.

### Measurements

Unmet demand, wait time by severity, resource conservation, fairness across groups, and operator override frequency.

### Next implementation steps

Add deadlines and multiple resource types; simulate shortages; review priorities with affected communities before any real allocation.

### Failure modes

Severity gaming, discriminatory allocation, starvation of low-priority cases, and treating different resources as interchangeable.

### Sponsor or collaborator fit

Community repair network or nonprofit service coordinator; start with a synthetic capacity-planning workshop.

### Runnable source

`labs.core.allocate` in `labs/core.py`. Run all examples with `python -m labs.demo`; inspect `tests/test_labs.py`.

### Six-week milestone proposal

Weeks 1–2: specify data and assumptions with an independent reviewer. Weeks 3–4: extend the demonstrator and run a preregistered baseline comparison. Weeks 5–6: publish reproducible results, failure cases, and a go/no-go recommendation. This schedule is a planning estimate, not a commitment or evidence of feasibility beyond the bounded software task.

Success means a reproducible result and honest limitations, including a null or negative result. No lab, clinical, animal, radiation, or environmental intervention is authorized by this proposal.
